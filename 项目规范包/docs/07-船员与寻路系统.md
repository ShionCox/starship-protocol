# 14. 船内寻路需求

这是项目核心技术模块之一。

## 14.1 导航图

不要直接在连续坐标中寻路，将飞船转换成导航图：

```text
房间站位
↕
房间出口
↔
相邻房间
↕
电梯
↔
特殊连接
```

## FR-NAV-001 路径搜索

建议 A*。P0。

## FR-NAV-002 路径缓存

布局没有变化时缓存 `fromNode → toNode → Path`。P0。

## FR-NAV-003 导航图重建

房间新增/拆除、电梯改变、船体切换、特殊通路改变时重建。P0。

## FR-NAV-004 目标失效

目标房间损毁、目标人员死亡或任务取消时必须重新决策。P0。
