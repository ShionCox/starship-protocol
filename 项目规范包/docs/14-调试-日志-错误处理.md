# 38. 调试工具

开发阶段必须建设 Debug Overlay。

至少显示：

```text
FPS
Draw Calls
Nodes
Game Tick
Tick Time
Crew Count
Room Count
Projectile Count
Event Count
Seed
Battle Hash
Current Scene
Loaded Bundles
Memory（可获取时）
```

## 38.1 战斗调试

需要：Pause Tick、Step 1 Tick、5x/10x 模拟、显示导航图、显示 Crew Path、显示 AI 当前命中的 Rule、显示 Weapon Target、导出 Snapshot、导出 Replay。

这是后期排查复杂 AI 战斗问题的关键工具。

# 39. 日志系统

统一 Logger：

```ts
logger.debug();
logger.info();
logger.warn();
logger.error();
```

分类：BOOT、ASSET、NETWORK、SHIP、CREW、NAV、AI、BATTLE、REPLAY、SAVE、UI。

正式版可以关闭高频 debug。

# 40. 错误处理

必须处理：

- Asset 加载失败；
- API 超时；
- Token 过期；
- Config Version 不一致；
- Battle Service 超时；
- Replay 数据损坏；
- 本地缓存损坏；
- WebGL Context Lost；
- 页面切后台；
- 网络断开。

不得简单黑屏。
