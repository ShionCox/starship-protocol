# Cocos 创作工具类型接入规范

> 本文件是“创作工具可识别类型接入”的唯一主文档。资源与 Prefab 的通用规则见 [`05-资源与Prefab规范.md`](./05-资源与Prefab规范.md)，测试与验收见 [`16-测试-验收-DoD.md`](./16-测试-验收-DoD.md)。

## 1. 适用范围与里程碑门槛

`extensions/starship-editor-tools/` 是项目唯一的创作工具宿主。房间、NPC、关卡等内容按领域模块接入同一个宿主，不创建第二个插件生命周期，也不为尚未进入里程碑的领域创建空菜单、占位 Prefab 或万能实体编辑器。

本规范只约束编辑器创作边界，不改变运行时规则入口。插件关闭、加载失败或识别失败时，场景运行、GameCore 测试和构建必须继续工作。

## 2. 类型注册契约

每个可识别类型必须显式注册一个 `AuthoringObjectRecognizer`，并声明以下固定信息：

| 字段 | 要求 |
| --- | --- |
| 稳定类型 ID | 小写、短横线命名，跨版本保持稳定，例如 `room-instance`。不得使用节点名或数组索引作为 ID。 |
| 所属页面 | 只能指向已经实现的领域页；页面不存在时禁止注册。 |
| 权威识别组件 | 优先使用公开组件类型或 CID；组件类名与压缩 CID 都要兼容。 |
| 节点名规则 | Boot/Main/Battle 标准骨架只识别中文语义名；业务实例不得靠节点名猜测类型。 |
| 白名单 DTO | 只返回面板需要的稳定字段、节点 UUID/名称/路径、只读状态和错误信息。禁止原始 Component dump。 |
| 中文字段说明 | 每个字段标注中文名称、用途、单位和只读/可写边界。 |
| 校验入口 | 声明可复用的 GameCore、RoomView 或场景配置校验入口；保存前重新读取并校验。 |

识别器按固定顺序执行：房间实例 → 船员实例 → 飞船实例 → 中文标准语义节点 → 普通节点回退。新类型必须插入明确位置并补测试，不能通过“扫描全部组件”自动暴露。

## 3. 数据边界

- 业务实例与共享定义分离。实例 ID、定义 ID、逻辑格位置和校验结果属于实例 DTO；名称、分类、尺寸和规则数值属于共享 CSV 定义行。
- Scene 数据使用公开 Scene API 读取、`set-property` 写入和 Scene snapshot 保存；配置数据使用公开 Asset DB 读取、校验和 `save-asset` 保存。
- 不序列化 Node、Prefab 实例、Color/Asset 对象、世界像素坐标或未经筛选的组件对象。网格内容必须转换为整数逻辑坐标。
- 稳定 ID、Prefab 引用和资源路径只读。可写属性必须有白名单、范围校验、失败回滚和一次 Undo 快照。
- 组件识别只能依赖公开组件类型/CID。禁止私有 hierarchy API、`cce.*`、DOM 注入和直接编辑 `.scene`、`.prefab`、`.meta` 文本。

## 4. 面板行为

面板可见时每 500ms 读取公开 Selection；隐藏或关闭时停止。只有选中 UUID 变化才自动切换页面和资源，强制刷新或保存不会因为 UUID 未变化而抢走用户手动选择的分页或资源。创建房间后 Creator 自动选中新节点，面板应立即显示其实例属性。

每个识别结果至少显示节点名称、路径和类型语义。识别失败、定义缺失、组件缺失或场景配置非法时显示中文错误和可继续处理的只读信息，不显示空白面板，也不把未知组件字段透传给用户。

房间、船员、船体、地板和连接器目录是项目级 Asset DB 资源库，不属于当前 Scene。P8 目录由九张运行时权威 CSV（七张玩法表与两张视觉表）和一张仅编辑器使用的 `editor-prefabs.csv` 映射表生成；扩展监听 `asset-db:asset-change` 并向面板发送目录变化通知。目录更新只刷新资源列表，不因 UUID 未变化抢走用户分页或手动资源选择。

当前 Scene 只提供显式实例放置目标：飞船创建到选中的 Main/Battle 挂载点；房间创建到选中的 ShipView 房间容器；船员创建到选中的目标 RoomView 所属 ShipView。没有明确作用域时必须中文报错，不回退到 Canvas 或场景根。目录资源不得复制到场景清单，也不得因为切换 Scene 而丢失。

R1 P8 使用 `HullDefinition` schema 2、`RoomDefinition` schema 3、`CrewDefinition` schema 4。房间、船员和船体表单编辑对应 CSV 行，整批跨表校验通过后才能保存；`RoomView`、`CrewView` 和 `ShipView` 仍只返回白名单 DTO，不得透传原始组件 dump。

R1 P7 的 PSS 素材页只返回白名单索引 DTO：支持中文名称、别名、实体 ID、source ID、类别和分页搜索；`fandom`、`uncategorized` 只显示诊断数量，不提供自动导入入口。导入必须先通过 manifest 的来源/目标路径、Hash、帧矩形和授权状态校验，再调用公开 Asset DB 或受控文件导入端口。插件关闭后，运行时不得依赖外部 `pss_full`。

视觉资源的 SpriteFrame 裁切、船员头/身/腿组合、锚点和 AnimationClip 引用属于编辑器资产操作，不写入 GameCore 快照。面板可以预览和选择素材，但不能把外部绝对路径、原始 JSON 或组件 dump 透传给运行时；Prefab 重开后必须能从持久引用恢复同一视觉 ID 和播放参数。

### 4.1 原生通知与就地详情

创作面板统一使用 Cocos Creator 公开的 `Editor.Task.addNotice` 作为短暂 Toast，不新增自定义 Toast、运行时 UI 或第三方依赖。通知 `source` 固定为“星舰创作工具”，类型与自动消失时间固定为：成功 `success/3000ms`、普通信息 `log/4000ms`、警告 `warn/6000ms`、错误 `error/8000ms`。Toast 只显示标题和不超过约 220 字的摘要；Creator 异常栈、场景阶段和完整校验信息必须继续留在相关面板的就地详情区。

进行中状态、自动预览成功和轮询刷新只更新按钮禁用态、状态徽标或就地详情，不产生 Toast。用户主动执行的保存、创建、导入、绑定和场景更新完成后只发送一次结果通知；同一作用域、同一内容的后台错误在短时间内去重。未保存草稿和选择冲突继续显示可操作横幅，并额外发送一次警告通知。

危险操作必须使用公开 `Editor.Dialog.warn`，取消不发送通知；接口缺失或调用失败时 fail-closed，停止写入并发送错误通知。CSV 文件选择必须使用公开 `Editor.Dialog.select({ type: 'file', multi: true })`；取消返回 `cancelled: true`，视为正常取消，不发送失败通知。

## 5. 新类型接入模板

提交新领域类型时，在同一批修改中填写并实现：

```text
稳定类型 ID：<domain-object>
所属里程碑/页面：<R1/...>/<page>
权威识别组件：<公开类名 + CID 兼容策略>
标准语义节点：<无；或仅列出骨架中文名>
只读 DTO：<字段、中文说明、单位>
可写字段：<字段、范围、保存入口>
定义资源：<CSV 表名、稳定行 ID 与 schemaVersion>
实例资源：<Scene/Prefab 路径与稳定实例 ID>
校验入口：<函数或公开组件方法>
错误状态：<缺失、非法、冲突时的中文提示>
自动测试：<识别、渲染、保存、回滚、普通节点回退>
Creator 证据：<选择、属性、保存、Undo/Redo、Console 截图>
```

### 接入完成检查表

- [ ] 对应里程碑已开始，未创建占位领域入口。
- [ ] 注册了稳定类型 ID、页面和顺序明确的识别器。
- [ ] 类名/CID 识别、中文字段说明、白名单 DTO 和只读/可写边界齐全。
- [ ] 共享定义与场景实例分离，保存使用公开 Asset DB/Scene API。
- [ ] 缺失资源、非法数据、冲突和写入失败都有中文状态与回滚。
- [ ] 自动测试覆盖识别、普通节点回退、属性显示、合法/非法保存和单次 Undo。
- [ ] Creator 3.8.8 人工选择与重载证据已持久化到 `docs/evidence/`。
- [ ] 验证插件关闭后运行、测试和构建不受影响。

## 6. 明确禁止

禁止万能属性编辑器、未经过滤的组件 dump、仅靠节点名猜类型、私有 Cocos API、DOM 注入、直接改序列化文件、把世界坐标写入规则存档、为未来领域提前注册空菜单，以及没有自动测试或 Creator 证据的“代码完成”声明。
