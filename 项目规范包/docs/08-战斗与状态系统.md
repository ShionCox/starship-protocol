# 15. 战斗系统需求

## 15.1 战斗阶段

```ts
type BattlePhase =
  | 'PREPARING'
  | 'COUNTDOWN'
  | 'ACTIVE'
  | 'ENDING'
  | 'RESULT';
```

## 15.2 每 Tick 推荐顺序

```text
01 读取 Command
02 更新能源
03 执行 AI 条件判断
04 生成 AI Command
05 更新船员任务
06 更新寻路
07 更新房间操作员效果
08 更新武器装填
09 创建 Projectile
10 更新 Projectile
11 命中/闪避判定
12 护盾结算
13 房间/船体/船员伤害
14 状态效果
15 火灾
16 医疗
17 维修
18 死亡
19 胜负判断
20 输出 Event
21 生成 State Hash
```

顺序一旦发布不得随意修改，修改必须升级 `battleRuleVersion`。

# 16. 伤害模型需求

```ts
interface DamagePayload {
  systemDamage: number;
  hullDamage: number;
  crewDamage: number;
  shieldDamage: number;
  armorPiercing: number;
```

R1 可简化为：房间/系统伤害、船体伤害、船员伤害、护盾伤害、火灾、EMP。

R2 再增加：穿甲、AOE、特殊状态、DOT。

# 17. 武器系统需求

## 17.1 武器状态

```ts
type WeaponState =
  | 'OFFLINE'
  | 'CHARGING'
  | 'READY'
  | 'FIRING'
  | 'COOLDOWN';
```

## FR-WEAPON-001 装填

由基础速度、能源、船员和状态共同决定。P0。

## FR-WEAPON-002 目标

支持手动目标、AI 目标、目标优先级和目标失效重新选择。P0。

## FR-WEAPON-003 弹道

GameCore 只计算逻辑命中与时间；Cocos 负责激光、导弹飞行、轨迹、爆炸和屏幕震动。P0。

# 18. 护盾与闪避

## FR-DEF-001 护盾

护盾具有当前值、最大值、恢复速度，并受能源、船员和 EMP 影响。P0。

## FR-DEF-002 闪避

由引擎、能源、驾驶和 Buff/Debuff 计算。P0/P1。

随机判定必须使用 Seed RNG。

# 19. 火灾和状态效果

## 19.1 通用 StatusEffect

```ts
interface StatusEffect {
  id: string;
  type: string;
  sourceId: string;
  targetId: string;
  startTick: number;
  durationTicks: number;
  stack: number;
}
```

R1 状态：Fire、EMP、Healing、RepairBoost。

R2+ 可增加 Poison、Freeze、Stun、ArmorBreak、ReloadBuff、EvasionDebuff。

所有状态以 Tick 为单位。
